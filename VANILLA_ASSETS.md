# Vanilla Assets

Some assets in this media kit reference or incorporate Minecraft's vanilla fonts and styling.
These are not included in this repository, you will need to obtain them separately from Mojang/Microsoft.

## Fonts

- Mojangles: https://minecraft.wiki/w/Mojangles#Downloads
- Minecraft Ten: https://minecraft.wiki/w/Minecraft_Ten#Downloads

Minecraft fonts and assets are property of Mojang Studios / Microsoft.
Refer to [Minecraft's usage guidelines](https://www.minecraft.net/en-us/terms) for permitted use.
